# Advanced tools UI checks

Screenshots are from a loopback-only preview with visibly labelled synthetic
fixtures. They are not screenshots of the live private document collection.
Desktop CSS viewport: 1600 × 1111. Phone CSS viewport: 390 × 844. Screenshots
retain the browser's capture scale. Full-page phone captures extend below the
viewport. DOM widths were checked to avoid mistaking a desktop preview for a
phone test.

The attached views show the main manager with Import/Export, the review step,
simplified Tools navigation, readable catalogue internals, and phone metadata
and module actions. Manual checks cover every Advanced tab, required-name
validation, rename prefilling, document membership moves, module/image uploads,
ZIP replacement, local export confirmation, additive library import, accessible
labels and menus. Real indexing and publication were not triggered.
