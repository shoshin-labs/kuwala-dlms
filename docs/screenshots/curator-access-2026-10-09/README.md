# Live curator and reader verification

Captured on 9 October 2026 from the independently deployed Jetson catalogue
and Pi visitor reader, using a normal desktop viewport and a 390 × 844 phone
viewport. The phone override was reset after capture.

The manager uses Django administrator login on the private Tailscale HTTPS
listener. It shows 108 originals in the main catalogue and real PDF text/vector
index status. Its Farming view is filtered to “goat” to show one of the new
imports; the **All documents** count remains 108. Upload, import, library and
document reindex controls are shown. No credential is included in these images.

The visitor reader retains the existing 85 published originals. Its snapshot
adds actual catalogue modification dates while preserving all 18,802 existing
passage IDs and original bytes. “Last updated in this library” means the last
catalogue/file save, not a new publisher edition or a rights/expert approval.
The **Manage Library** link opens the separate private login.
