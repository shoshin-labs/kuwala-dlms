# Compact catalogue navigation — 11 October 2026

These screenshots use a loopback preview on port 8798 with visibly synthetic
originals and records. They show 50 library choices and, in the Health fixture,
51 sections. This is a navigation stress check, not a production corpus or a
search-capacity benchmark.

Mobile views use a 390 × 844 CSS viewport; desktop views use 1280 × 900.

- [Phone document](after-mobile-document.jpg), [first screen](after-mobile-document-top.jpg)
- [Phone manager](after-mobile-manager.jpg)
- [Desktop document](after-desktop-document.jpg)
- [Desktop manager](after-desktop-manager.jpg)
- [Expanded desktop library/section picker](after-desktop-expanded.jpg)

The original-document action is near the title and the location picker begins
closed on document and selected-library views. The expanded lists scroll inside
bounded areas and support separate library and section searches. The ordinary
manager upload, edit, import/export and scope actions remain available.
