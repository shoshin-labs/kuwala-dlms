# PDFs for practical use cases and classroom teaching

This is a **17-item source-review shortlist**, not an import or published release. It adds seven education resources and ten practical references to consider within the existing Oasis catalogue. Original-serving, indexing, answer, translation, domain and technical-advice approval remain false for every item.

Start with these use cases:

1. **Teach early number sense:** Bala Wande Grade 1 provides a daily sequence for counting, matching and sorting, with weekly assessment. It is bilingual isiXhosa/English; learner books/posters are companion resources.
2. **Prepare lower-primary classroom routines:** Funda Wande gives daily literacy/life-skills planning. Its English edition is a teacher reference for an African home-language programme, not English phonics or a Chichewa syllabus.
3. **Teach practical science through a school garden:** FAO supplies age-differentiated lesson outlines using local crops, observation, water and simple budgets. Its original educational/noncommercial grant is conditional.
4. **Support African food production:** the indigenous leafy-vegetable manual and agroforestry primer add Kenyan/tropical crop and tree-planning contexts with clear attribution licences. Beekeeping and two aquaculture guides add specialised training with noncommercial conditions.
5. **Address school and household needs:** school sanitation, accessible household WASH, menstrual-health planning, solar fish drying and heat preparedness fill different contexts. Four have unresolved whole-PDF redistribution grants and remain held.
